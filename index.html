회사 AI API 연결

API 키는 이 사이트에 입력하지 마세요

이 공개 GitHub Pages는 비밀키를 안전하게 보관할 수 없습니다. 회사가 승인한 HTTPS 중계 서버를 별도로 구축한 뒤 그 주소만 연결합니다. 회사 API가 사내망 전용이라면 회사 내부 중계 서버가 필요합니다.

중계 서버 API 계약 (개발자용)
GET /health → {"status":"ok"} POST /analyze 요청: {"task":"question"|"notice_summary","question":"...","document":{"title":"...","url":"...","text":"..."},"sources":[{"title":"...","url":"...","text":"..."}]} 응답: {"answer":"...","citations":[{"title":"...","url":"..."}]} 서버는 HTTPS, CORS 허용 출처 제한, 인증/접근제어, 요청량 제한, 비밀키 서버 보관을 구현해야 합니다. 이 화면만으로 회사 API가 연결되는 것은 아닙니다.
