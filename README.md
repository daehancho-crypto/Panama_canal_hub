# Panama Canal Hub

GitHub Pages: https://daehancho-crypto.github.io/Panama_canal_hub/

Goal: collect ACP Advisory to Shipping and Notices to Shipping automatically without scheduled AI calls. AI summarization is manual only.

Official sources:
- https://pancanal.com/en/maritime-services/advisory-to-shipping/
- https://pancanal.com/en/maritime-services/notices-to-shipping/

The current index.html is a landing page. Do not treat it as a verified current regulation database. Never store an API key in HTML or repository files.
